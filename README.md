# Yusuke-114 Homebrew Tap

Homebrew tap for yusuke-114 apps.

## Install Steward

```sh
brew tap yusuke-114/tap
brew install --cask steward
```

Or install directly:

```sh
brew install --cask yusuke-114/tap/steward
```

For `brew bundle`:

```ruby
tap "yusuke-114/tap"
cask "steward"
```
